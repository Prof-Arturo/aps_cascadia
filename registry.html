Classification Key (Periphenomena)
🚪 TYPE I LIMINAL Spatial distortions, missing time, threshold crossings, places that don't quite fit. Digital-substrate cases (feeds or devices behaving as though responsive to thought) also fall here.
🐾 TYPE II CRYPTO-BIOLOGICAL Encounter with an unknown biological entity. Tracks, vocalizations, behavior. Distinguished from Type VI by physical evidence.
🛸 TYPE III AERIAL / TECHNICAL Lights in the sky, structured craft, drone-like behavior, mechanical or hardware failure.
💭 TYPE IV NOETIC / PSYCHIC Interior experiences — anomalous dreams, premonitions, telepathic impressions, knowing things you shouldn't.
🪑 TYPE V POLTERGEIST / MATERIAL Physical interaction with the environment — objects moving, knocks, apports, marks or traces.
👁 TYPE VI ENTITY / THRESHOLD Non-biological entity contact — figures seen at the edge of sleep or in full waking consciousness, ancestral visitation, shadow figures, what folklore calls "the seen."
🗺️ TYPE VII PLACE / GENIUS LOCI Locations with persistent unusual reports across many witnesses over time. Window areas, sacred sites, places with multi-generational histories.
⚡ TYPE VIII ENERGETIC / ENVIRONMENTAL Diffuse phenomena without an identified source — the Hum, infrasound, electromagnetic anomalies, persistent geophysical strangeness.
🌐 TYPE IX CULTURAL / COSMOLOGICAL Experiences explicitly framed within a specific cultural, indigenous, religious, or spiritual tradition. The witness's own framework is preserved as primary.
