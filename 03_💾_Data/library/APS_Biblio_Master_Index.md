## What changed in v4.0, in one paragraph

The library was built against the **v3.0 five-type taxonomy** and was never extended when the taxonomy grew to nine. Types VI–IX had no bibliography at all, while three of those four — VI, VII, VIII — already had outreach packages in circulation, so the project was soliciting reports in categories it held no scholarship for. v4.0 rebuilds the library against the v4.1 canonical taxonomy: eleven files instead of seven, 63 citations instead of 44, Markdown instead of .docx, numbered to the class codes the registry uses, with boundary notes added so the files are usable for coding rather than only for reading. Two citations were removed, two were refiled, and four bibliographic errors were corrected. 🌐 Type IX is deliberately left provisional under a consultation hold.

## Bibliographic corrections

Four errors in v3.0, verified against library catalogues and publisher records. Each is noted in its own file as well, so the correction travels with the citation.

**1. Vallée, *Passport to Magonia*** — v3.0 gave `ISBN 978-0841503557`. That ISBN belongs to **Keel's *Mothman Prophecies***, two entries below it in the same file, and was duplicated by copy error. The 1969 Henry Regnery first edition carries **no ISBN**, which is correct for a pre-1970 imprint. Cite OCLC [44880](https://search.worldcat.org/oclc/44880), or the Daily Grail 2014 reprint (ISBN 9780987422484). v3.0's OCLC for this work (838526) could not be confirmed against a 1969 Regnery record.

> **Trap for anyone re-checking this:** Google Books' record for the 1969 H. Regnery edition attaches 2014 reprint identifiers (ISBN 0987422472 / 9780987422477, OCLC 1001840131) to it. Do not cite those for 1969.

**2. Adler, *Sleep Paralysis*** — v3.0 gave "New York: Rutgers University Press, 2011. ISBN: 9780190616459" with a `global.oup.com` link. Three errors: Rutgers UP is in **New Brunswick, NJ**; `9780190616459` is an Oxford ISBN and not this book; the link pointed to a different publisher. Correct: New Brunswick, NJ: Rutgers University Press, 2011, Studies in Medical Anthropology. **9780813548869** (pbk.), 9780813548852 (hbk.), 9780813552378 (ebook).

**3. Type IV glyph** — v3.0 used 🛌 throughout. Current is **💭**. See *Glyph note* above.

**4. Taxonomy legend** — v3.0's "CODE LEGEND: THE 5 PHENOMENA" cited *APS Master Data Protocol v3.0*. The MDP is now v4.2 and the taxonomy has nine types. Replaced.

## Citation standard

**Chicago notes-bibliography.** Author inverted, title in italics, place, publisher, year.

Each entry carries, in order: the citation line, all available stable identifiers, an annotation, and a metadata line.

```
### Author, Name — *Title: Subtitle*

Place: Publisher, Year. ISBN 978…. OCLC [number](url). DOI [10.…](url).

Annotation: what the work argues, and what an APS analyst uses it for.
The second sentence is the one that earns the entry.

`WEIGHT` · `frame: …` · cross-ref → 💭 IV, 👁 VI
```

### Weight tags

| Tag | Meaning |
|---|---|
| `CORE` | Foundational. In the reading order. |
| `KEY` | Important, not foundational. |
| `CONTESTED` | Advocacy, or disputed on method within its own field. Cite with the dispute. |
| `PRIMARY SOURCE` | Not scholarship — an artefact of the phenomenon or its repertoire. |
| `JOURNALISM` | Press, not peer-reviewed. |

### Frame tags

| Tag | Meaning |
|---|---|
| `frame: mechanism` | Proposes a conventional explanatory mechanism. |
| `frame: anomalistic` | Treats the phenomenon as potentially irreducible. |
| `frame: cultural` | Treats it as a meaning-making or narrative object. |
| `frame: method` | About procedure rather than about any phenomenon. |

**The frame tag is apparatus, not a ranking, and it is where methodological agnosticism becomes structural rather than aspirational.** Labelling which stance a work takes — without ordering the stances — is what lets the archive hold Naish beside Heuvelmans, and French beside Tandy, without adjudicating. A file whose entries are all one frame is a file with a blind spot, and the imbalance is visible at a glance: 🚪 Type I is almost entirely `cultural`, ⚡ Type VIII almost entirely `mechanism`. Both are noted in their own *Gaps*.

### House rules

1. **One home per citation.** A work is filed where an analyst would look for it, and cross-referenced from everywhere else. The only exception is Smith, dual-listed because it governs method generally and binds hardest in Type IX.
2. **Cross-reference, don't duplicate.** Types VI–IX each carry a cross-reference table; those tables are load-bearing, since three of the four have more borrowed reading than native.
3. **Titles are quoted verbatim**, including words the project does not use in its own prose — *supernatural*, *paranormal*, *psychic*. Fidelity to the source is the same principle as fidelity to the witness. Annotations follow `voice_style_guide.md`.
4. **Internal register applies.** The library is analyst-facing, so theoretical vocabulary is in scope per the Iceberg Method. Nothing here is witness-facing.
5. **Never invent an identifier.** Blank beats plausible. See *Deliberately incomplete*.
6. **Gaps are content.** Every file ends with what it is missing, named specifically enough to act on. An unmarked gap gets forgotten; a named one gets filled.

## Scope and naming — a deliberate exception

**These files carry no `_Reg10_Cascadia` suffix, and should not.**

Scholarship is not regional. Hufford applies in Cascadia and in Appalachia; Tuan does not become a different book at a bioregional boundary. Suffixing these files would imply a Cascadia-specific reading list and would require nine near-identical copies as the project scales to its other bioregional units.

This resolves one class of file under NOTE 3 of `APS_Project_Structure_v4.1.txt` ("naming convention partially applied") on a principle rather than by sweep. The principle:

> **Region suffix if the content is region-specific.** `APS_Field_Manual_Reg10_Cascadia.docx` describes Cascadia fieldwork. `APS_Master_Data_Protocol.docx` is marked *national* and carries no suffix. The library is national and carries no suffix.

The same reasoning applies to `APS_Elevator_Pitches.md`, which NOTE 3 also flags: its framing is national, its delivery is Region 10, and it is correctly unsuffixed.

**Region-specific bibliographic material** — the Cascadia site history at gap 5, for instance — would be a separate regional file (`APS_Biblio_Reg10_Cascadia_Sites.md`) rather than a suffixed copy of a national one.

## Format

Markdown, replacing seven `.docx` and one `.txt`.

| | v3.0 | v4.0 |
|---|---|---|
| Files | 8 | 12 |
| Size on disk | ~2.2 MB | ~130 KB |
| Per-file | ~317 KB for ~3 KB of text | text only |

Each v3.0 `.docx` embedded the same logo, so the library was roughly 2.2 MB of repository for 25 KB of citations, and every version bumped the whole binary. Markdown is greppable (`grep -rn "Type_VI" library/` finds the bibliography alongside the outreach package), diffable line by line in review, and linkable from `registry.html` and the press kit without conversion. It also matches the existing convention for reference documents — `voice_style_guide.md`, `data_storage_architecture.md`, `APS_Elevator_Pitches.md`.

The `.docx` originals should be retained in `x0N_Legacy Revisions/` rather than deleted; they are the only record of the five-type library.

## Extracted — APS Dictionary Entry 001

v3.0's Methodology bibliography carried **APS Dictionary Entry 001: Periphenomena** — etymology, pronunciation, part-of-speech, usage examples, and the five-type table.

It has been removed from the bibliography and reissued as [`APS_Glossary.md`](../../01_✒️_Admin/APS_Glossary.md) in Admin, reconciled against Mission Statement §2.0. A glossary is not a bibliography, and the entry should not have been inside one.

**It also contradicted canon in three places,** which is the substantive reason for the move rather than a filing preference. See the glossary's own reconciliation note; in summary, v3.0 asserted that periphenomena are "physically real but transient or elusive", that they are events "the human brain or current scientific instruments struggle to categorize", and that "we study the peripheral natural". All three are ontological or explanatory commitments that Mission Statement §2.0 explicitly declines to make.
